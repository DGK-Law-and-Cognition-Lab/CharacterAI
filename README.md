# Character AI research program

Materials and code from the DGK Law and Cognition Lab (UCLA Department of Psychology) on how people form relationships with AI chatbots and how they judge responsibility when a chatbot user is harmed.

- OSF project: <https://osf.io/cnxdu>
- `study1/`: Study 1 (chatbot warmth). Code and materials; not preregistered.
- `study2/`: Study 2 (chatbot anxiety). Code and materials; preregistered on OSF, May 7, 2026.
- `crossstudy/`: exploratory analyses that combine Studies 1 and 2.
- `studies1-2_materials/`: the consent form, debrief and structured conversation outline approved for Studies 1-2.
- `study3/`: Study 3 (chatbot warmth × extraversion). See `study3/README.md`.

Participant data are not stored in this repository. Studies 1-2 data are available to qualified researchers under a data use agreement, as their consent form states.
