# Character AI research program

Materials and code from the DGK Law and Cognition Lab (UCLA Department of Psychology) on how people form relationships with AI chatbots and how they judge responsibility when a chatbot user is harmed.

- OSF project: <https://osf.io/cnxdu>
- `study3/`: Study 3 (chatbot warmth × extraversion). See `study3/README.md`.

Participant data are not stored in this repository.
