# Data notice

The analyses in this folder combine Study 1 and Study 2 and are exploratory. They read the Study 1 and Study 2 session data and `measurement/bot_turn_tone_probes.csv` (tone-probe scores of each chatbot reply, keyed by participant). None of these data files are in this repository. As the Studies 1-2 consent form states, de-identified data may be shared with qualified researchers under a data use agreement; contact David G. Kamper, davidgkamper@ucla.edu.

Paths written as `<PROJECT_ROOT>` stand for the lab's project folder.

This release contains the code as of November 2026. The analyses are being re-run; the revised code will be a later release.
